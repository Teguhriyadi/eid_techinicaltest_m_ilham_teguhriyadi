# Smart Manufacturing Dashboard

Web-based Smart Manufacturing Dashboard untuk monitoring mesin produksi dan pengelolaan laporan hasil produksi pada lingkungan manufaktur.

Project ini dibuat untuk Technical Test **PT Electrindo Inti Dinamika** dengan tujuan membangun sistem monitoring produksi yang dapat membantu melihat performa mesin, aktivitas operator, serta rekap hasil produksi.

---

# 🚀 Features

## Authentication

Fitur autentikasi pengguna:

- Login
- Logout
- Proteksi halaman


---

## Machine Management

Pengelolaan data mesin produksi.

Fitur:

- Melihat daftar mesin
- Menambahkan data mesin
- Mengubah data mesin
- Menghapus data mesin
- Mengatur status mesin


Status mesin:

- Running
- Idle
- Maintenance
- Error


---

## Operator Management

Pengelolaan data operator produksi.

Fitur:

- Melihat daftar operator
- Menambahkan operator
- Mengubah data operator
- Mengatur status aktif operator


---

## Production Management

Fitur pencatatan aktivitas produksi.

Data produksi yang dicatat:

- Mesin produksi
- Operator
- Jumlah produksi
- Temperatur mesin
- Status mesin
- Shift produksi
- Waktu produksi


---

## Smart Manufacturing Dashboard

Dashboard monitoring produksi yang menampilkan:

- Total mesin
- Jumlah mesin running
- Jumlah mesin idle
- Jumlah mesin maintenance
- Jumlah mesin error
- Jumlah operator aktif
- Total produksi hari ini
- Grafik produksi berdasarkan waktu
- Monitoring aktivitas produksi


---

## Production Report

Fitur laporan produksi digunakan untuk melihat histori dan rekap hasil produksi.

Fitur:

- Melihat histori produksi
- Rekap produksi harian
- Rekap berdasarkan shift
- Rekap berdasarkan mesin
- Detail data produksi
